対生成AI判別用 画像周波数分布解析ツール Web UI

⚠️ 本ツールは 私的利用かつローカル実行専用です。 公開サーバへのデプロイ／SNS 画像の自動取得は行いません。

1. 画像と設定

PNG / JPEG / WebP / BMP / TIFF（最大 20 MiB）。

ナイキスト半径基準。カンマ／空白区切りで複数指定。

マスク縁ぼかし。リンギング軽減に。

bandpass モード時のみ使用。

OFF にすると mean を足した素の出力（高周波が暗く／白く潰れて見える）。

二値化（白黒化）

X 投稿の 2〜4 枚目のような白黒エッジ画像を出力します。

黒地→白地に反転します。

fixed 選択時のみ使用。既定 127。

情報量マップ（参考: Zenn 記事の軽量版）

local_contrast 用。短辺の 1/16〜1/8 が目安。

0=原画のみ / 1=ヒートマップのみ。
